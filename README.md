# Web Search LLM Agent

A command-line AI agent that uses Google Gemini and SerpAPI to answer questions with live web search.

## Setup

1. Install dependencies:
   pip install google-genai serpapi python-dotenv

2. Create a .env file in the project folder:
   GEMINI_API_KEY=your_key_here
   SERPAPI_KEY=your_key_here

3. Run:
   python AI_Agent.py

Type exit to quit.
